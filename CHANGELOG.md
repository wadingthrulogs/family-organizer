## [Unreleased]

Everything on `main` since 0.1.0. No version has been tagged yet.

### Added

**Meal plans & recipes**
- Weekly meal planner with breakfast, lunch, dinner and snack slots, recipe management, inventory checks for ingredients, and "send to grocery" (0a161c3, 2a0c719).
- Bulk recipe import: paste text, or upload JSON that is parsed in the browser (f9627f0).
- Ingredient status per recipe (in stock / out of stock / not in inventory) and ingredient autocomplete (2bbec52).
- Meals are shown on the calendar (d0c7f48).
- **Prepared-meal tag** on inventory items. Tagging an item creates a linked single-ingredient recipe automatically; untagging deletes it (fe269a8).

**Inventory**
- **Recipe photo import.** On the Inventory page, upload or take a photo of a recipe, receipt or groceries. A host-side headless Claude Code watcher (`tools/recipe-image-watcher/`) extracts the items, you edit the preview, and the items are bulk-added. New endpoints: `POST /inventory/extract-from-image` and `POST /inventory/bulk-items`. Extraction reuses the household's existing category labels (4c577a7, 126d513, 649be39, e48202a).
- Inventory upgrades: a mobile compact view, and a three-state Low/Out cycling button (579cd8c, e294358, 74e2264).
- Inventory widget: all-items view, low-stock filter, search, inline quantity editing and a mark-out button (53d68b3, f77119e).

**Commute**
- Commute widget with live ETAs and an inline traffic map, backed by Mapbox geocoding and directions. Configure routes in Settings → Commute (1d08260, f8db17f).
- Automatic "leave-by" ETAs for upcoming calendar events that have a location (1a7c695).

**Tasks**
- Recurring tasks now actually recur: marking one DONE creates the next instance (285cec9).
- Task retention: DONE tasks are soft-deleted after 30 days and hard-deleted after 90. Runs daily at 03:00 or on demand via `POST /tasks/cleanup` (ADMIN) (eb7a00c).
- Quick-add with an assignee from the Tasks widget, and a quick-add FAB on mobile (081f834, b03d6be).

**Dashboard & kiosk**
- Dashboard background photos with overlay opacity and a fill/fit toggle (6bbec10, 10ef551).
- Redesigned the dashboard for a 1080p touch kiosk (ba7552f, 2d1626a).
- Kiosk got a settings sheet and its own config (`kiosk-config` / `kioskConfig`), separate from the dashboard (1679919, 17941f5, 5c1547e).
- Per-widget font size control in edit mode (fbdc80e).
- A separate saved layout for portrait (md, 8-column) screens (0300c2e).
- Weekly events view shows every event for each day (076795f).
- Edit-mode UX: undo on widget remove, and drag handles in the widget header (6cd7431).

**Calendar**
- Google Calendar sync button, plus a force re-sync (`POST /integrations/google/:accountId/full-sync`) (d0c7f48, 2a6cf2f).
- Sync errors are shown per account (`lastSyncError`) (2a6cf2f).

**UX**
- Accessibility, empty states and a modal overhaul (044a960).
- Better dates, statuses and filters (c658ee8).
- A grocery, inventory and meal-plan pass (0a6ec57).
- Mobile pass: touch targets, safe areas, dropdown clipping (30390ee, 3560a0b, 2172bb0, 43591ed, 801660a).
- Customisable mobile bottom bar, decoupled from tab visibility. The Dashboard tab can now be hidden (a17c12c, 857ea8b, 1ad50ff).
- Reminders and Notifications pages, and a new app layout component (bd2f51f).

**Tooling**
- MCP server (`mcp/`) exposing 15 organizer tools to Claude over stdio or HTTP/SSE (fe705b8).
- Developer agents (`agents/`): frontend expert and Dashboard Architect Pro (032ae76, b71bbbb).
- Playwright e2e suite with landscape and portrait projects (3610ea2, 5cc60ce).
- Docs for each of these: `mcp/README.md`, `agents/README.md`, `e2e/README.md`, `tools/recipe-image-watcher/README.md`.

### Changed

- **Tasks page is now a simple todo list.** It's grouped, with quick-add and All/Active/Done/Mine filters, and replaces the Kanban board from 0.1.0 (90523d6).
- Theme set renamed. The 16 themes are now: default, dark-plus, light-plus, monokai, dracula, solarized-dark, solarized-light, one-dark-pro, nord, **midnight**, **paper**, catppuccin-mocha, catppuccin-latte, gruvbox-dark, tokyo-night, rose-pine. GitHub Dark/Light are gone (a54edb9).
- Secrets (`SESSION_SECRET`, `ENCRYPTION_KEY`) are generated by `setup.sh` into `backend/.env` and the root `.env`. They're no longer generated inside the container, where they were lost whenever the volume was recreated (462805d).
- Calendar sync is now asynchronous and incremental (`syncToken`). It also gained bulk fetch, a mutex, a 24 h auth-error cooldown and a daily full re-sync (df6e666, 8a6e71d, 83cb631).
- Calendar events are grouped by local day, not UTC (4ae8096). The calendar widget now uses an agenda list with flipped axes (eb61546).
- Widget text is denser: non-clock/weather widgets render at 60% font size (66c369b).
- Performance: route-level code splitting, targeted kiosk invalidation, QueryClient defaults (30 s stale, no refetch on focus), stable query keys, and less frequent clock ticks (b140c0b, e4197e1, ab2a155, 276a592, 30f446b).
- **Deployment (this branch):**
  - The frontend nginx now serves **plain HTTP by default**. It switches to HTTPS automatically at container start if `TLS_HOSTNAME` is set or a single cert pair is mounted at `/etc/tailscale/certs`.
  - `HTTP_PORT` / `HTTPS_PORT` (default 80 / 443) replace `APP_PORT`.
  - The backend container now loads `backend/.env` through `env_file`, optional and overridden by explicit compose values. This means Google, SMTP, VAPID, OpenWeather and `WEBHOOK_URL` set there actually take effect.
  - `tailscale-setup.sh` no longer patches `nginx.conf`. It writes `TLS_HOSTNAME`, `APP_BASE_URL` and `SESSION_SECURE` to `.env` and installs cert renewal in root's crontab.
  - Recipe watcher bind mounts default to `${HOME}/uploads` and `${HOME}/recipe-output`, overridable with `RECIPE_UPLOADS_HOST_DIR` / `RECIPE_OUTPUT_HOST_DIR`.
  - `setup.sh` quick-start updates the root `.env` in place instead of rewriting it.

### Fixed

- User deletion, backup export/import, attachment access hardening, and nginx security headers (400330d, df4f879, bddf653, a388e0e).
- Dashboard drag and resize stability:
  - free-form layout via `noCompactor` (c50f7cd, 47a1fc6);
  - `preventCollision` removed (fc54749);
  - no mid-drag re-renders (4576e18, 921de57, f1fec07, 0fb9c13);
  - no breakpoint thrash at the grid edge (656400e);
  - layout persistence guarded by a container-width ref (b2714c0).
- A stale server config no longer overwrites an edited local dashboard or kiosk config (eb99c93, 089b766).
- Kiosk-mode bugs and kiosk layout persistence (32ed006, 1679919).
- Google Calendar edits to recurring events are now reflected (1709750). Calendar sync blocks until complete, so events show up on refresh (8a6e71d).
- Tasks: the silent 20-task cap in the UI is gone; infinite query pages are flattened in the widget (eb7a00c, 98ba548).
- The inventory `lowStock` filter is no longer always on (4afa200), and inventory mutations were fixed (25cbca2).
- The dashboard background image now fits mobile screens (2e5b9d8).
- Fresh installs: port 80 no longer redirects to an unpublished HTTPS port, and `tailscale-setup.sh` no longer produces an nginx config that fails to start (this branch).

### Removed

- The Kanban board, and the `@dnd-kit` drag-and-drop on Tasks. The package is still listed in `frontend/package.json` but nothing imports it.
- Zustand (276a592).
- Committed build artifacts (`dist-v0.1.0.tar.gz`, `backend-dist-v0.1.0.tar.gz`), `tsc-output.txt`, and two uploaded photos in `backend/uploads/` that contained GPS EXIF data (this branch). The photos are still in git history.

## [0.1.0] — 2026-02-22

Initial public release. (Some 0.1.0 features were later replaced; see [Unreleased].)

### Added

**Task Management**
- Kanban board with OPEN / IN_PROGRESS / BLOCKED / DONE / ARCHIVED columns
- Task assignments to multiple household members
- Priority levels (0–5), due dates, and labels
- Recurring tasks (daily, weekly, biweekly, monthly, yearly)
- Status change history log
- Drag-and-drop card reordering

**Chores**
- Chore templates with round-robin, weighted, and manual rotation
- Auto-generated assignments with configurable windows
- Skip and swap assignment actions
- Streak tracking per user per chore
- Reward points system

**Grocery Lists**
- Multiple named shopping lists with optional store tag
- Shopping mode (high-contrast dark UI optimized for in-store use)
- Item states: NEEDED → CLAIMED → IN_CART → PURCHASED
- Natural-language bulk add
- Auto-populate list from low-stock inventory items

**Inventory**
- Pantry/household item tracker with quantity and unit
- Low-stock threshold alerts
- Natural-language bulk add
- Move purchased grocery items directly to inventory
- CSV-style text export

**Calendar**
- Google Calendar OAuth integration (multiple accounts per household)
- Day / week / month views
- Manual event creation with color coding
- Background sync with last-sync status

**Reminders & Notifications**
- Reminder rules linked to tasks, chores, or arbitrary targets
- Web Push notifications (VAPID)
- Optional SMTP email delivery
- Per-reminder lead time and channel selection
- Admin-triggered notification processing

**Users & Access Control**
- Session-based authentication with bcrypt password hashing
- Three roles: ADMIN, MEMBER, VIEWER
- Admin user management (create, reset password, change role, soft delete)
- Per-user color tag for assignment display

**Dashboard**
- Drag-and-resize widget grid (react-grid-layout)
- Widgets: Clock, Weather, Tasks, Chores, Overdue Chores, Grocery, Events, Reminders, Inventory
- Layout persisted per user

**Theming**
- 16 built-in themes: Default, Dark+, Light+, Monokai, Dracula, Solarized Dark/Light, One Dark Pro, Nord, GitHub Dark/Light, Catppuccin Mocha/Latte, Gruvbox Dark, Tokyo Night, Rosé Pine

**Settings**
- Household name, timezone, quiet hours
- Weather widget (OpenWeatherMap integration)
- Hidden tabs per user
- Backup export / import (ADMIN)

**Deployment**
- Docker Compose setup (frontend + backend, single `docker compose up`)
- Automatic database migrations on container start
- Nginx-based frontend container handles SPA routing and API proxying
- Attachment file uploads (up to 10 MB, magic-byte validated)
